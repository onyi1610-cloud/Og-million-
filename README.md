## 🚀 How to Use

### **Option 1: Local Access**
1. Download all files (index.html, styles.css, script.js)
2. Open `index.html` in your web browser
3. Click the audio button (🔊) to control background music

### **Option 2: GitHub Pages (Recommended - PUBLIC ACCESS)**

#### Step 1: Enable GitHub Pages
1. Go to your repository: https://github.com/onyi1610-cloud/Og-million-
2. Click **Settings** → **Pages**
3. Under "Source", select **main** branch
4. Click **Save**

#### Step 2: Access Your Live Website
GitHub will deploy your site to: `https://onyi1610-cloud.github.io/Og-million-/`

**Your website is now PUBLIC and anyone can view it!** 🌍

### **Option 3: Use Live Server (VS Code)**
1. Install "Live Server" extension in VS Code
2. Right-click `index.html`
3. Select "Open with Live Server"
4. Website opens automatically with auto-reload

## 🎨 Customization

### Change Profile Picture
In `index.html`, line 80:
```html
<img src="YOUR_IMAGE_URL" alt="Profile" class="profile-img">
```

### Modify Colors
In `styles.css`, update CSS variables (lines 11-18):
```css
--primary-color: #00d4ff;      /* Cyan */
--secondary-color: #ff006e;     /* Pink */
--accent-gold: #ffd700;         /* Gold */
```

### Update Background Music
In `script.js`, line 10:
```javascript
const playlists = [
    'YOUR_MUSIC_URL_1',
    'YOUR_MUSIC_URL_2',
];
```
